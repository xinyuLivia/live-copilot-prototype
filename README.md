# 实况智能体 · Live Copilot（交互原型）

无人机巡检平台「任务实况」页上的大模型对话智能体交互原型（单文件、纯前端、可动态演示）。

- **一阶段 · 实况洞察**：对当前帧 / 告警图 / 10s 短视频用自然语言提问，返回计数 / 拥堵 / 隐患等研判结论卡（只读）。
- **二阶段 · 智能操控**：自然语言下达飞行 / 取证指令 → 任务计划卡 → 人工确认 → 执行（流程示意）。
